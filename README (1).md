# Mohamed Jauhar Kottappurath — Physiotherapist Portfolio

A one-page portfolio site for a Dubai-based physiotherapist. Plain HTML/CSS/JS —
no build step, so it runs directly on GitHub Pages.

## Files
- `index.html` — all page content and structure
- `styles.css` — design system (colors, type, layout)
- `script.js` — mobile menu toggle + footer year
- `profile.jpg` — headshot used in the hero section

## Status
Contact details (email + both phone numbers) and the Bachelor of Physiotherapy
credential are already filled in with real information — no placeholders left
to replace.

## Optional next additions

  "Download CV" button in `index.html` to link to `cv.pdf` instead of

- **Employer / clinic name** — once attached to a specific Dubai facility,

## Notes on accuracy
The DHA certificate states the registration is not itself a permit to practice —
it is activated into a licence once attached to a licensed facility. The
credentials section is worded to reflect that accurately.
